## Read `context.md` first

Before changing anything in this repo, read [`context.md`](./context.md) — it holds the
architecture decisions, environment traps, verification status, and backlog that aren't
derivable from the code. Update it in the same commit whenever you make a non-obvious
decision or open/close a backlog item.
